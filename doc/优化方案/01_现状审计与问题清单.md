## 一、已确认缺陷（源码证据）

### 1. 文件写入无原子性 — 崩溃即损坏

- **证据**: `../../src-tauri/src/commands.rs` L550-553  
  ```rust
  pub async fn write_file(path: String, content: String) -> Result<(), String> {
      validate_path(&path)?;
      fs::write(&path, &content).map_err(|e| format!("写入文件失败: {}", e))
  }
  ```
- **影响**: 写入中途崩溃/断电 → 文件截断或清空，笔记不可恢复
- **优先级**: P0

### 2. `save_note` 静默吞错误

- **证据**: `../../src-tauri/src/commands.rs` L191-194  
  ```rust
  pub fn save_note(id: String, content: String) {
      let path = notes_dir().join(format!("{}.md", id));
      fs::write(&path, &content).ok();
  }
  ```
- **影响**: 磁盘满/权限错误时用户无感知，数据静默丢失
- **优先级**: P0

### 3. `restore_backup` 无路径校验

- **证据**: `../../src-tauri/src/commands.rs` L1009-1014  
  ```rust
  pub fn restore_backup(backup_path: String, target_path: String) -> Result<(), String> {
      let content = fs::read_to_string(&backup_path)...;
      fs::write(&target_path, &content)...
  }
  ```
- **影响**: 前端可传任意 `target_path`，覆盖系统文件
- **优先级**: P0

### 4. 自动保存不触发备份

- **证据**: `../../src/App.tsx` L1064-1068 — debounce 2s 后调用 `handleSaveRef.current()`  
  `../../src/App.tsx` L998-1051 — `handleSave` 内调用 `create_backup`，但 `handleSaveSplit`(L1076-1089) **不调用** `create_backup`
- **影响**: 分屏编辑永远不产生版本历史；主窗格仅手动/自动保存时备份，但 README 声称"1.5 秒自动保存"实际为 2 秒
- **优先级**: P0

### 5. 搜索为暴力递归遍历，无索引

- **证据**: `../../src-tauri/src/commands.rs` L689-739 `search_in_files_recursive` — 逐文件逐行 `find()`
- **影响**: 1000+ 篇笔记时搜索耗时数秒，阻塞 UI（虽为 async 但无分页/取消）
- **优先级**: P1

### 6. 知识图谱每次保存全量重建

- **证据**: `../../src/App.tsx` L844-847 — `handleSave` 成功后调用 `refreshKnowledgeIndex(currentDir)`  
  `../../src/App.tsx` L437-482 — `refreshKnowledgeIndex` 调用 `read-all-notes` 读取目录全部 .md
- **影响**: 大库下每次保存触发全量 IO + 解析，造成卡顿
- **优先级**: P1

### 7. 外部修改检测用 5 秒轮询

- **证据**: `../../src/App.tsx` L544-568 — `setInterval(..., 5000)` 调用 `get_file_modified`
- **影响**: 延迟高、无效 IO 多；不使用 Tauri fs watcher 或 notify crate
- **优先级**: P1

### 8. `validate_path` 范围过宽

- **证据**: `../../src-tauri/src/commands.rs` L8-23 — 允许 `home_dir()` 下所有路径 + `/tmp`
- **影响**: 前端被 XSS 后可读写用户主目录下任意文件（SSH 密钥、浏览器数据等）
- **优先级**: P1

### 9. CSP 过于宽松

- **证据**: `../../src-tauri/tauri.conf.json` L23  
  `"script-src 'self' 'unsafe-inline' 'unsafe-eval'; connect-src 'self' https: http://localhost:*"`
- **影响**: `unsafe-eval` 允许 eval()，`connect-src https:` 允许向任意 HTTPS 发请求
- **优先级**: P1

### 10. App.tsx 单体 1685 行，30+ useState

- **证据**: `../../src/App.tsx` L131-233 — 连续声明 30+ state/ref
- **影响**: 可维护性差、渲染性能隐患（任何 state 变化触发整棵树 re-render）
- **优先级**: P2

### 11. 无测试覆盖

- **证据**: `find . -name "*.test.*" -o -name "*.spec.*"` 返回空；`package.json` 无 test script
- **影响**: 回归风险极高，重构无安全网
- **优先级**: P1

### 12. Agent 模块为 SQL Agent 无关代码

- **证据**: `../../src/agent/AgentManager.ts` L19 `name: 'SQL Agent'`；`../../src/agent/types.ts` L19-27 `AgentContext` 含 `connectionId`/`databaseType`/`tables`
- **影响**: 死代码增加包体积、误导开发者；笔记 AI 功能实际由 `AIPanel.tsx` + `ai_chat` command 提供
- **优先级**: P0（清理）

### 13. `delete_file` 命令永久删除

- **证据**: `../../src-tauri/src/commands.rs` L557-564 — `remove_file` / `remove_dir_all`
- **影响**: 虽然 Sidebar 用 `move_to_trash`，但 `delete_file` 仍注册在 invoke_handler 中，前端其他路径可调用
- **优先级**: P1

### 14. 自动保存 debounce 与 README 不一致

- **证据**: README L65 声称 "1.5 秒自动保存"；`../../src/App.tsx` L1067 实际为 `setTimeout(..., 2000)`
- **影响**: 文档与实现不一致
- **优先级**: P2

### 15. 编辑器状态缓存仅 10 个

- **证据**: `../../src/components/Editor.tsx` L174-177 — `stateCacheRef.current.size > 10` 时淘汰最早 key
- **影响**: 多标签用户（>10 篇）切换时丢失 undo 历史
- **优先级**: P2
