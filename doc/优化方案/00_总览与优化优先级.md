## 项目定位

z-biz-tool-note（ZenNote）是一款 **本地优先** 的跨平台 Markdown 笔记应用，基于 Tauri 2 + React 19 + Tiptap v3 构建。  
独特价值：纯文件存储（用户拥有数据）、所见即所得 + 源码双模式、知识图谱 + 双向链接 + 嵌套标签、多标签 + 分屏、AI 助手、离线可用。

## 核心原则（贯穿全部方案）

1. **自动保存不丢数据** — 任何崩溃/断电场景下，用户最多丢失 2 秒输入
2. **原子写防损坏** — 文件写入必须 temp + rename，禁止直接覆盖
3. **危险操作可撤销** — 删除/覆盖/恢复均进回收站或版本历史，30 天可回退
4. **Agent 不自动破坏笔记** — AI/Agent 仅可建议，写入需用户显式确认
