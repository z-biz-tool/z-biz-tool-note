## 一、笔记完整流程覆盖分析

### 1.1 新建笔记

| 维度 | 当前状态 | 缺口 | 优先级 |
|------|----------|------|--------|
| 快捷键新建 | ✅ Cmd+N 创建内存笔记 | 未落盘前崩溃即丢失 | P1 |
| 文件夹右键新建 | ✅ Sidebar `handleNewFile` 写入磁盘 | 无模板选择、无 frontmatter | P2 |
| 每日笔记 | ✅ Cmd+Shift+D | 无自定义日期格式/目录规则 | P2 |
| 从模板新建 | ⚠️ 仅"插入模板"到已有笔记 | 缺少"以模板新建"入口 | P2 |
| 剪贴板快速笔记 | ❌ 无 | 对标 Obsidian Quick Add | P2 |

**建议**：新建即落盘（创建空 .md 到当前目录），避免内存态笔记丢失；新增 frontmatter 模板（title/date/tags）。

### 1.2 编辑与自动保存

| 维度 | 当前状态 | 缺口 | 优先级 |
|------|----------|------|--------|
| WYSIWYG 编辑 | ✅ Tiptap v3 全功能 | — | — |
| 源码模式 | ✅ Cmd+/ 切换 | 无独立语法高亮源码编辑器 | P2 |
| 自动保存 | ✅ 2s debounce | 无保存状态指示器（saving/saved/error） | P1 |
| 保存失败反馈 | ❌ 前端不处理 write_file 错误 | 静默失败 | P0 |
| 冲突检测 | ⚠️ 5s 轮询 mtime + confirm | 无 diff 合并、无"保留两者" | P1 |
| 打字机模式 | ✅ | — | — |
| 专注模式 | ✅ | — | — |

**建议**：  
- StatusBar 增加保存状态微标（● 未保存 / ⟳ 保存中 / ✓ 已保存 / ⚠ 保存失败）  
- 保存失败时 toast + 重试按钮 + 本地 WAL 兜底  
- 冲突时提供三向 diff（本地 vs 磁盘 vs 共同祖先）

### 1.3 Markdown 与所见即所得

| 维度 | 当前状态 | 缺口 | 优先级 |

| 代码高亮 | ✅ 12 语言预加载 | 其余 180+ 按需加载未验证 | P2 |
| 表格编辑 | ✅ 可调列宽 | 无 CSV 粘贴自动转表格 | P2 |
| 脚注 | ❌ | 学术笔记常用 | P2 |
| 目录生成 `[TOC]` | ❌（有 Outline 面板但无内嵌 TOC） | 对标 Typora | P2 |

**建议**：优先支持 YAML frontmatter 解析（影响标签、图谱、导出元数据）；脚注和 `[TOC]` 为 P2。

### 1.4 组织：文件树 / 标签 / 双链

| 维度 | 当前状态 | 缺口 | 优先级 |
|------|----------|------|--------|
| 递归文件树 | ✅ 按需展开 | 无拖拽移动文件 | P1 |
| 嵌套标签 | ✅ Bear 风格 | 无标签重命名/合并 | P2 |
| WikiLink 双链 | ✅ `[[title]]` | 无自动补全弹窗（仅 SlashCommand） | P1 |
| 反向链接 | ✅ 面板展示 | 无"未链接提及"（unlinked mentions） | P2 |
| 知识图谱 | ✅ 力导向图 | 无局部图谱（当前笔记 N 跳） | P2 |
| 收藏/置顶 | ❌ | 高频笔记无法快速访问 | P2 |
| 笔记本/工作区隔离 | ❌ 单目录 | 多项目用户需切换 | P2 |

**建议**：  
- 文件树支持拖拽移动/排序（调用 `rename_file`）  
- WikiLink 输入 `[[` 时弹出笔记标题自动补全（复用 QuickSwitcher 数据源）  
- 增加"局部图谱"视图（以当前笔记为中心 2 跳）

### 1.5 全文搜索

| 维度 | 当前状态 | 缺口 | 优先级 |
|------|----------|------|--------|
| 全局搜索 | ✅ 暴力遍历 | 无索引、无高亮、无分页 | P1 |

| 替换 | ✅ 单文件内 Cmd+F | 无全局批量替换 | P2 |
| 搜索历史 | ❌ | — | P2 |

**建议**：引入 SQLite FTS5 索引（Rust 侧），支持 `tag:`/`path:`/`"` 精确/正则；结果分页 + 高亮。

### 1.6 附件与图片

| 维度 | 当前状态 | 缺口 | 优先级 |
|------|----------|------|--------|
| 图片粘贴/拖拽 | ✅ 保存到 images/ | 无压缩/缩放选项 | P2 |
| 图片 Lightbox | ✅ | — | — |
| 附件管理面板 | ❌ | 无法查看/清理孤立附件 | P1 |
| 附件相对路径 | ✅ `images/xxx.png` | 笔记移动后路径断裂 | P1 |

- 增加"孤立附件检测"工具

### 1.7 历史版本

| 维度 | 当前状态 | 缺口 | 优先级 |
|------|----------|------|--------|
| 版本备份 | ✅ 保留 20 版 | 仅 Cmd+S 触发，自动保存不备份 | P0 |

- 版本 diff 视图（红绿对比）

### 1.8 导入导出

| 维度 | 当前状态 | 缺口 | 优先级 |
|------|----------|------|--------|
| HTML 导出 | ✅ 简易 Markdown→HTML | 不含样式/图片/公式 | P1 |
| PDF 导出 | ⚠️ `window.open` + print | Tauri WebView 中可能不工作 | P1 |
| Markdown 导出 | ✅ 原文件即 .md | — | — |
| 批量导出 | ❌ | 无法一键导出整个笔记本 | P2 |
| 导入 .docx/Notion/Obsidian | ❌ | 用户迁移成本高 | P2 |
| 导出脱敏 | ❌ | 分享时可能泄露 API Key/路径 | P1 |

**建议**：  
- HTML 导出使用 Tiptap `getHTML()` 保留完整样式  
- PDF 导出改用 Rust 侧 `wkhtmltopdf` 或 Tauri print API  
- 增加"导出为 zip"（含附件）  
- 导出时自动移除 frontmatter 中的敏感字段

## 二、交互体验提升

### 2.1 保存状态可视化

当前 StatusBar 仅显示 `isDirty` 和 `lastSaved` 时间。  
**建议**：增加三态微标 + 错误重试入口。

### 2.2 文件树拖拽

当前 Sidebar 文件树无拖拽。  
**建议**：支持拖拽移动文件/文件夹（调用 `rename_file`），拖拽到编辑器插入链接。

### 2.3 标签页右键菜单增强

当前有：关闭/关闭其他/关闭右侧/复制路径。  
**建议**：增加"在 Finder 中显示"、"固定标签"、"重命名"。

### 2.4 搜索体验

当前搜索输入即触发全量遍历（无 debounce）。  
**建议**：300ms debounce + 取消前次请求 + 结果虚拟列表 + 关键词高亮。

### 2.5 欢迎页与引导

当前 Welcome 组件提供基本入口。  
**建议**：增加"最近编辑"、"库统计"（笔记数/字数/标签数）、新手引导 tour。
